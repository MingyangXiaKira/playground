# Web3 AI 时代学习路径

源文件：`index.html`

## 打开网页

本地：打开仓库里的 `index.html`。

上线（需要小夏点一次 GitHub Pages）：

1. 打开 https://github.com/MingyangXiaKira/playground/settings/pages
2. Build and deployment → Source 选 **Deploy from a branch**
3. Branch 选 **web3-ai-path** / **/ (root)** → Save
4. 一两分钟后打开 https://mingyangxiakira.github.io/playground/

GitHub Actions 工作流已写好，但第一次需要仓库打开 Pages 权限，否则会在 `configure-pages` 失败。
